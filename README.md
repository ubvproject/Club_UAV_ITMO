## Как сдать решение — 5 шагов

Своя папка = свой ник на GitHub. Пример: ник `ivan-petrov`, задача 21.10 →
`resheniya/2026-10-21_razvedka_3x3/ivan-petrov/`. В чужие папки и вне `resheniya/` ничего не меняйте —
автопроверка такой запрос не пропустит.

**Через сайт GitHub (без git):**

1. Нажмите **Fork** вверху страницы — у вас появится своя копия репозитория.
2. В своей копии откройте `resheniya/<папка задачи>/` → **Add file → Create new file**. В имени файла наберите
   `ivan-petrov/README.md` (косая черта создаёт папку), вставьте [шаблон](resheniya/_shablon/README.md),
   заполните → **Commit changes**.
3. Откройте свою новую папку → **Add file → Upload files** → перетащите файлы решения → **Commit changes**.
4. На главной странице своей копии: **Contribute → Open pull request**.
5. Дождитесь зелёной галочки автопроверки. Красный крестик — откройте его, там написано, что поправить.

**Через git:**

```bash
git clone https://github.com/<ваш-ник>/Club_UAV_ITMO.git && cd Club_UAV_ITMO
git checkout -b razvedka_3x3
mkdir -p resheniya/2026-10-21_razvedka_3x3/<ваш-ник>
cp resheniya/_shablon/README.md resheniya/2026-10-21_razvedka_3x3/<ваш-ник>/
# положите туда решение и заполните README.md
python3 tools/check.py            # та же проверка, что на GitHub
git add resheniya && git commit -m "Разведка 3x3: решение" && git push -u origin razvedka_3x3
```

Затем на GitHub: **Compare & pull request**. Исправить решение — коммит в ту же ветку, запрос обновится сам.

Подробно о правилах — [CONTRIBUTING.md](CONTRIBUTING.md).

## Что нельзя класть

Репозиторий **открытый** — его видит весь интернет.

- пароли, токены, ключи симулятора, логины от судейского пульта;
- видео, архивы (`.zip`, `.7z`), файлы больше 5 МБ — видео полёта загрузите в чат секции или в облако
  и вставьте ссылку в `README.md`;
- материалы МКБ под NDA, решения из папок «тренеру»;
- чужой код без указания автора.
