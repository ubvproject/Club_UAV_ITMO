# Правила сдачи решений

## Участникам

1. **Одна задача — одна папка:** `resheniya/<папка задачи>/<ваш ник на GitHub>/`. Ник — строчными буквами,
   как в адресе вашего профиля `github.com/<ник>`.
2. В папке обязательно `README.md` по [шаблону](resheniya/_shablon/README.md). Строку `Результат:` читает сводка —
   пишите в ней цифры (баллы, время, ошибку), а не «всё работает».
3. Всё остальное — свободно: `solution.py`, свои модули, картинки, CSV-логи. Каждый файл — до 5 МБ.
4. Изменения только через pull request из своего форка или ветки. Прямо в `main` не пишет никто.
5. Автопроверка (вкладка **Checks** в запросе) смотрит:
   - файлы лежат в вашей папке и только в ней;
   - есть `README.md`;
   - `.py` без синтаксических ошибок и неизвестных имён (ruff);
   - нет видео, архивов, больших файлов и похожего на пароли и токены.
6. Тренер смотрит решение, оставляет комментарии и вливает запрос. Улучшили решение после влития — новый запрос
   в ту же папку.
7. Списывать нельзя, учиться у чужих решений — можно и нужно. Взяли идею или кусок кода — напишите в `README.md`, у кого.

### Частые ошибки автопроверки

| Сообщение | Что сделать |
|---|---|
| `файл вне вашей папки` | перенесите файлы в `resheniya/<задача>/<ваш ник>/` |
| `нет README.md` | скопируйте шаблон в свою папку |
| `имя папки` | только латиница в нижнем регистре, цифры и `-`, как ник на GitHub |
| `нет такой задачи` | папка задачи должна совпадать с папкой в `zadachi/` |
| `похоже на секрет` | уберите пароль или токен из кода; если уже запушили — смените его |
| `запрещённый тип` / `больше 5 МБ` | видео и архивы — ссылкой в `README.md` |

## Тренерам

**Новая задача:**

1. `zadachi/<ГГГГ-ММ-ДД>_<коротко_латиницей>/README.md` — условие, что сдать, как проверяется, срок.
2. Пустая папка `resheniya/<та же папка>/` с `.gitkeep`.
3. Строка в таблицу задач в главном `README.md`.

Авторские решения, ответы и сценарии занятий сюда **не класть** — репозиторий открытый.

**Приёмка:** запрос с зелёной проверкой → запустить решение (для сима — «Судейский пульт» → «Загрузить скрипт
команды» → «Зачётный запуск»), записать итог комментарием → **Merge**. После влития обновить сводку:

```bash
python3 tools/check.py --svodka
```

**Настройки GitHub (один раз):**

- Settings → Branches → правило для `main`: Require a pull request, Require status checks (`check`).
- Settings → Actions → General → «Require approval for first-time contributors» — оставить: первый запуск
  проверки у нового участника подтверждает тренер.
- Участникам без форка можно дать доступ: Settings → Collaborators → роль **Write**.
