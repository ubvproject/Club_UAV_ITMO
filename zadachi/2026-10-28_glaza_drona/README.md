## Что сдать

`resheniya/2026-10-28_glaza_drona/<ваш ник>/`:

- `p1_…py` … `p5_…py` — файлы, в которых `raise NotImplementedError` заменены вашим кодом;
- `БЛАНК.md` — заполненный;
- по желанию: `calib_bort.json` (из `out/` после `p4 --bort`), `p3_bort.csv`, 1–3 картинки из `out/`;
- `README.md` по шаблону; в строке `Результат:` — какие практикумы проходят целиком и f вашего борта,
  например `Результат: p1–p4 все [ ОК ], p5 — 2 TODO; f = 662 пикс (номинал 656)`.

Общие файлы архива (`ubv_cv.py`, `check_env.py`, `data/`) не кладите — они у всех одинаковые.

## Как проверяется

Тренер запускает каждый `pN_….py` рядом с `ubv_cv.py` из архива: все проверки должны быть `[ ОК ]`. Цифры
в `БЛАНК.md` сверяются с протоколом бортов.
